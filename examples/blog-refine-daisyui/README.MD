## Quick Start

Run the following command to download the project:

```
npm create refine-app@latest -- --example blog-refine-daisyui
```

Once the setup is complete, navigate to the project folder and start your project with:

```
npm run dev
```

Your application will be accessible at http://localhost:5173

Feature explanation:
Once the application is started, we can see all the three columns combined together into a single one.
There are 3 dropdowns available under Select data to compare.
A maximum of 2 data can be selected.
There is also a date picker which helps to customise the graph based on any date.
Any clash between the start and end date will indicate an error message and the filter will be reset automatically.
